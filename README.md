# 灰色の契約 GREY CONTRACT

初代PS風の低ポリグラフィックで遊ぶ、傭兵メカアクションゲーム（ブラウザで動きます）。

依頼を受けて出撃し、報酬でパーツを買って機体を組み替えていきます。全6話のストーリーミッション付き。

## 遊ぶ

https://kanata-games.github.io/grey-contract/

## 操作（初期設定）

| 操作 | キーボード・マウス | ゲームパッド |
| --- | --- | --- |
| 移動 | WASD | 左スティック |
| 旋回・照準 | マウス / 矢印キー | 右スティック |
| 右腕武器 | 左クリック / J | RT |
| 背部武器 | 右クリック / E | LT |
| ブレード | F / 中クリック | RB |
| ジャンプ・上昇 | Space | A |
| ダッシュ | Shift | B |
| 一時停止 | P / Esc | START |

キー・パッドの割り当てはゲーム内の「システム」から変更できます。スマホではタッチ操作で遊べます。

## メモ

- 1ファイル構成（`index.html`）。3D描画に three.js r128（CDN）を使用
- セーブデータはブラウザの localStorage に保存
