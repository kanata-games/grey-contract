# 灰色の契約 GREY CONTRACT

初代PS風の低ポリグラフィックで遊ぶ、傭兵メカアクションゲーム（ブラウザで動きます）。

この世界の人型機動兵器は「GW（グレイ・ウォーカー）」と呼ばれています。

依頼を受けて出撃し、報酬でパーツを買って機体を組み替えていきます。

- ストーリーは全14話。第一部（6話）は入門編、第二部（8話）は高難易度の本編

- パーツ枠は 頭部・コア・腕部・脚部・ブースター・ジェネレーター・右腕・左腕・背部・オプション（3枠）の10種類、全112種
- 手持ち武器（銃・ブレード）は右手でも左手でも装備可能。二丁持ちや二刀流もできます
- 武器腕（両腕が銃になる腕部）、背部レーダー、チェインガン、プラズマキャノンなども搭載可能
- 話を進めるとショップに新しいパーツが入荷します
- 第1話クリアで「アリーナ」が解禁。10人のランカーと1対1で戦い、順位を奪い合います

## 遊ぶ

https://kanata-games.github.io/grey-contract/

## アプリとして入れる（PWA）

- **iPhone**：Safariで開く → 共有ボタン → 「ホーム画面に追加」
- **Android / PC（Chrome・Edge）**：アドレスバーのインストールボタン、またはメニューの「アプリをインストール」

ホーム画面から全画面で起動でき、一度読み込めばオフラインでも遊べます。

## 操作（初期設定）

| 操作 | キーボード・マウス | ゲームパッド |
| --- | --- | --- |
| 移動 | WASD | 左スティック |
| 旋回・照準 | マウス / 矢印キー | 右スティック |
| 右腕武器（銃・ブレード） | 左クリック / J | RT |
| 背部武器 | 右クリック / E | LT |
| 左腕武器（銃・ブレード） | F / 中クリック | RB |
| ジャンプ・上昇 | Space | A |
| ダッシュ | Shift | B |
| クイックブースト | Q | LB |
| 一時停止 | P / Esc | START |

キー・パッドの割り当てはゲーム内の「システム」から変更できます。スマホではタッチ操作で遊べます。

## メモ

- 1ファイル構成（`index.html`）。3D描画に three.js r128（CDN）を使用
- セーブデータはブラウザの localStorage に保存（iPhoneではホーム画面版とSafari版でデータが別になります）
- PWA: `manifest.webmanifest` と `sw.js`（ゲーム本体はネット優先、three.js・フォントはキャッシュ優先）
